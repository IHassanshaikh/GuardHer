## 🚀 Overview
This repository hosts the **GUARDHER** application, a comprehensive ride safety solution designed to empower users with preloaded emergency response capabilities. It enables passengers to securely share ride details and trusted contacts before a journey, and in case of an emergency, trigger instant alerts that dispatch critical ride data, live location, and timestamps to emergency services, ride-hailing partners, and selected contacts with minimal user interaction.

Built as a full-stack Next.js production service, GUARDHER is engineered with best practices, modular architecture, and automated CI/CD integration.

## ✨ Features

- **Autonomous Audit Verified**: Checked by GitHub AI Manager for security and best practices.
- **Strict Typing**: End-to-end TypeScript coverage and schema validation.

## 🛠️ Getting Started

### Prerequisites
- Node.js 18+ or Docker 24+
- Package manager (`npm` or `pnpm`)

### Installation
```bash

git clone <repo-url>
cd <repo-name>

# 2. Install dependencies
npm install

# 3. Configure environment
cp .env.example .env.local

# 4. Start development server
npm run dev
```
